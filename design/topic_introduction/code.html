Introduction to Cognitive Load Theory

Foundational Concepts

Cognitive Load Theory (CLT) is an instructional design framework that reflects our current understanding of how the human brain processes and stores information. Developed by John Sweller in the 1980s, it posits that our working memory has a limited capacity for acquiring new information, while our long-term memory has a virtually limitless capacity.

The central premise of CLT is that instructional design should aim to optimize the load on working memory to facilitate the transfer of learning into long-term memory. Overloading working memory with unnecessary or poorly presented information hinders the learning process.

lightbulb Key Definitions

  • Intrinsic Load: The inherent difficulty associated with a specific instructional topic. It is fixed and determined by the complexity of the material itself.
  • Extraneous Load: The cognitive effort required to process poorly designed instruction. This is the load that instructional designers should strive to minimize.
  • Germane Load: The cognitive effort dedicated to processing, constructing, and automating schemas (meaningful learning). Instruction should seek to maximize this load within the limits of total working memory capacity.
